# Gestión de Solicitudes Académicas - Refactoring

Trabajo Práctico Integrador de Metodología de Sistemas II (UTN, Tecnicatura
Universitaria en Programación a Distancia).

Se parte de un módulo simple de gestión de solicitudes académicas hecho en
Python, se diagnostica su calidad interna y se mejora con refactorings
seguros, pruebas y una revisión de código.

Integrantes: Matías Orellana y Nicolás Pagola.

El repositorio se va completando por etapas. La documentación definitiva está
en `docs/`.
